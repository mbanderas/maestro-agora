# Improved Human Writing Layer

Agora now builds articles around the information users actually provide. It carries first-party examples, decisions, constraints, and numbers into planning, outlining, drafting, and revision. Sections receive the space their ideas need without a default three-part pattern.

Ordinary articles use the reader's language. The writing pass replaces internal review terms with the event, person, number, or decision that matters, while preserving the user's facts, attributed recommendations, requested structure, and voice. Sparse briefs stay useful without invented customer stories, experiences, statistics, or results.

This guidance runs inside Agora's existing generation flow. It does not add a separate review product or authorship score.

The final article pass includes a deterministic typography check when Node is available. It identifies characters for the writer to correct and leaves the draft unchanged.

Validation: 213 deterministic tests, package contents check, and public-tree hygiene passed. The versioned blind article evaluation is recorded in the release evidence.
