Explain CPU cache to a product engineering team using one analogy.

Facts: cache stores copies of recently or frequently accessed data closer to the processor. A hit can avoid a slower memory access. Cache capacity is limited. Data moves in cache lines, and coherence protocols coordinate copies across cores. The analogy must not imply that cache decisions are conscious, that every repeated access is cached, or that cache is simply faster storage with no consistency cost.

State what maps, what does not map, where the analogy breaks, and then return to the real mechanism.
