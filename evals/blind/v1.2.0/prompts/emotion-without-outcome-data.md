# Request

Write the product section of a public page for this system, around one hundred and twenty words, ending with the one action it offers.

## Supplied facts

- Marlow Box Office is a ticketing system used by amateur and community theatres.
- A volunteer builds the seating plan for a show by drawing rows and marking which seats are restricted view, which are wheelchair spaces, and which are held back for the cast.
- Once the first ticket for a show is sold, the seating plan is locked. Rows cannot be added, removed, or renumbered.
- A held-back seat can be released for sale at any point before the performance. A released seat cannot be held back again once it has been sold.
- If a performance is cancelled, the system marks every ticket for that performance as refundable and emails the ticket holders. It does not issue the refunds; a volunteer approves each one.
- Refund approval is limited to accounts with the treasurer role. There is one treasurer role per theatre and it cannot be shared between two people.
- The system supports one currency per theatre and cannot sell tickets in a second currency.
- The action available is a sandbox: a working copy of the system loaded with a sample show, where a volunteer can build a plan, sell a test ticket, and cancel a performance. It requires an email address and no payment details.
- No sales, attendance, refund-rate, or satisfaction figure is available. No theatre has agreed to be named.

## Constraints

- Use only the facts above.
- Do not invent numbers, named theatres, quotations, or results.
- Do not state what a volunteer or a treasurer feels, wants, worries about, or finds difficult.
- Do not claim the system is easy, simple, stress-free, or reassuring.
